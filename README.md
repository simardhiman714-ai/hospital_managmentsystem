# 🏥 Hospital Management System

A modern **Hospital Management System** developed using **Node.js, Express.js, EJS, MySQL, HTML, CSS, and JavaScript**. This project helps hospitals efficiently manage patients, doctors, user authentication, appointments, and contact messages through a clean and user-friendly interface.

---

## ✨ Features

### 👤 User Module
- User Registration
- User Login Authentication
- Dashboard

### 🩺 Doctor Management
- Add Doctor
- View Doctors
- Update Doctor Details
- Delete Doctor
- Search Doctor

### 🧑 Patient Management
- Add Patient
- View Patients
- Update Patient Details
- Delete Patient
- Search Patient

### 📅 Appointment Module
- Appointment Page
- Book Appointment UI

### 📞 Contact Module
- Contact Form
- Store Messages in MySQL Database
- Thank You Page after Submission

### 🌐 Website Pages
- Home
- About
- Services
- Doctors
- Contact
- Login
- Register
- Dashboard

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/simardhiman714-ai/hospital_managmentsystem.git
```

Move into the project

```bash
cd hospital_managementsystem
```

Install dependencies

```bash
npm install
```

Start the server

```bash
node app.js
```

Open in browser

```
http://localhost:3000
```
